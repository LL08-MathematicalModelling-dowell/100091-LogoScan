Welcome to CCTV Monitor Dashboard

This dashboard allows you to upload CCTV videos, perform object detection using YOLOv6, and explore detected objects in individual frames. Use the navigation bar to access the following features:

  • Upload: Upload a video and extract frames for processing.
  • Object Detection: Run object detection on extracted frames.
  • Frame Explorer: View frames with detected objects and filter by class.
